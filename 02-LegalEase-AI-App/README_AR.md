# تطبيق LegalEase الذكي

## نظرة عامة على المشروع

LegalEase هو تطبيق محمول مدعوم بالذكاء الاصطناعي مصمم لمساعدة الأفراد في إنشاء المستندات القانونية والشكاوى والعقود بسهولة دون الحاجة إلى معرفة قانونية مسبقة. يحول التطبيق مدخلات المستخدم (نص أو صوت) إلى تنسيق قانوني منظم مكتوب بلغة قانونية مهنية.

## بيان المشكلة

الكتابة القانونية غالباً ما تكون معقدة، ومعظم الناس غير مألوفين بالتنسيقات القانونية الصحيحة والنبرة والمصطلحات. توظيف محامٍ للمستندات القانونية البسيطة يمكن أن يكون مكلفاً ويستغرق وقتاً طويلاً. هناك حاجة لأداة بسيطة ومتاحة وذكية تساعد المستخدمين في صياغة المستندات القانونية وفهم العمليات القانونية بسهولة.

## أهداف المشروع

1. **توليد المستندات**: توفير تطبيق محمول يساعد المستخدمين في إنشاء المستندات القانونية تلقائياً
2. **تكامل معالجة اللغة الطبيعية**: استخدام معالجة اللغة الطبيعية (NLP) لفهم مدخلات المستخدم وإنتاج نص قانوني دقيق
3. **الوصول للمعرفة القانونية**: تبسيط الوصول للمعرفة القانونية من خلال الاستشارات المدعومة بالذكاء الاصطناعي
4. **إدارة المستندات**: ضمان تخزين جميع المستندات المُنشأة بأمان وإمكانية تصديرها بالتنسيقات الرسمية (مثل PDF)
5. **الوعي القانوني**: تعزيز الوعي القانوني في المجتمع من خلال التحول الرقمي

## نظرة عامة على النظام

يسمح LegalEase للمستخدمين بوصف مشكلتهم القانونية باللغة العربية أو الإنجليزية البسيطة. يحلل النظام بعد ذلك النص باستخدام نموذج ذكاء اصطناعي (GPT API أو Gemini API) لتحديد السياق وإنشاء مستند قانوني كامل ومهني مثل:

- خطابات الشكوى
- عقود الإيجار أو البيع
- نماذج الطلبات الرسمية
- ردود الاستشارات القانونية

يمكن بعد ذلك مراجعة المستند المُنشأ وتحريره وتنزيله أو مشاركته مباشرة من التطبيق.

## مميزات النظام

### المساعد الذكي
- **تحويل النص إلى قانوني**: يحول وصف المستخدم إلى مستند قانوني رسمي
- **مراجعة العقود**: يمكن للمستخدمين رفع العقود الموجودة والحصول على التصحيحات أو التوضيحات
- **الاستشارة القانونية**: روبوت محادثة مدعوم بالذكاء الاصطناعي للنصائح والتوضيحات القانونية

### التفاعل الصوتي
- **تحويل الكلام إلى نص**: يحول المدخلات الصوتية إلى نص لتوليد المستندات
- **دعم متعدد اللغات**: التعرف على الصوت باللغة العربية والإنجليزية

### إدارة المستندات
- **تصدير PDF**: يسمح للمستخدمين بحفظ وتنزيل المستندات بتنسيق PDF
- **مستنداتي**: تخزين المستندات المُنشأة مسبقاً مع البحث والمرشحات
- **التخزين السحابي**: نسخ احتياطي آمن لجميع الملفات والمستندات في السحابة

### تجربة المستخدم
- **المصادقة**: تسجيل دخول آمن باستخدام Firebase Authentication (البريد الإلكتروني/Google)
- **متعدد اللغات**: دعم اللغة العربية والإنجليزية
- **السمة المظلمة/الفاتحة**: تصميم حديث وسهل الاستخدام
- **الوضع غير المتصل**: الوظائف الأساسية متاحة بدون اتصال بالإنترنت

## هيكل النظام

يتبع المشروع مبادئ الهندسة المعمارية النظيفة للحفاظ على قابلية التوسع وفصل الاهتمامات.

### الطبقات

#### طبقة العرض (واجهة Flutter)
- مسؤولة عن تفاعل المستخدم وعرض الشاشات وإدارة الحالة
- تستخدم Provider أو Cubit لإدارة الحالة
- تطبق أنماط Material Design أو Cupertino

#### طبقة المجال
- تحتوي على منطق الأعمال والكيانات وحالات الاستخدام
- أمثلة: GenerateDocumentUseCase، SaveDocumentUseCase، ContractReviewUseCase
- تحدد واجهات المستودعات والقواعد التجارية

#### طبقة البيانات
- تتعامل مع استدعاءات API وتكامل Firebase ومستودعات البيانات
- تتضمن خدمة الذكاء الاصطناعي للاتصال مع OpenAI أو Gemini API
- تدير التخزين المحلي ومزامنة السحابة

## التقنيات المستخدمة

### الواجهة الأمامية
- **الإطار**: Flutter (Dart)
- **إدارة الحالة**: Provider أو Cubit
- **مكونات الواجهة**: Material Design 3
- **التخزين المحلي**: Hive أو SQLite
- **توليد PDF**: حزمة pdf

### الخادم الخلفي
- **وقت التشغيل**: Node.js مع Express.js
- **قاعدة البيانات**: MongoDB أو Firebase Firestore
- **المصادقة**: Firebase Authentication
- **تخزين الملفات**: Firebase Storage

### تكامل الذكاء الاصطناعي
- **الأساسي**: OpenAI GPT API
- **البديل**: Google Gemini API
- **معالجة الكلام**: Google Cloud Speech-to-Text
- **الترجمة**: Google Translate API

### خدمات السحابة
- **الاستضافة**: Vercel أو Render
- **CDN**: CloudFlare
- **المراقبة**: Sentry لتتبع الأخطاء

   - تاريخ المحادثة

7. **الملف الشخصي والإعدادات**
   - إدارة تفضيلات المستخدم
   - إعدادات اللغة والسمة
   - إدارة الاشتراك
   - إعدادات الخصوصية

## مخطط سير العمل

```
مدخلات المستخدم (نص/صوت)
    ↓
تحويل الكلام إلى نص (إذا كان صوت)
    ↓
كشف اللغة والترجمة
    ↓
معالج الذكاء الاصطناعي (الخادم الخلفي)
    ↓
توليد المستند القانوني
    ↓
معاينة وتحرير المستند
    ↓
حفظ/تصدير PDF
```

## الأمان والخصوصية

- **تشفير البيانات**: جميع بيانات المستخدم والمستندات المُنشأة مشفرة
- **المصادقة**: Firebase Authentication يضمن حماية هوية المستخدم
- **الخصوصية**: لا يتم مشاركة البيانات الشخصية مع APIs الخارجية بدون موافقة المستخدم
- **التخزين الآمن**: الملفات مشفرة قبل حفظها في التخزين السحابي
- **امتثال GDPR**: معالجة بيانات المستخدم تتبع لوائح الخصوصية
