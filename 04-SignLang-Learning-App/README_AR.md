# تطبيق تعلم لغة الإشارة

## نظرة عامة على المشروع

تطبيق SignLang هو تطبيق تعليمي تفاعلي محمول مصمم لتعليم لغة الإشارة بطريقة ممتعة ومرئية وجذابة. يوفر للمستخدمين مقاطع الفيديو والقواميس والاختبارات وغرف الدردشة والألعاب لمساعدتهم على تعلم وممارسة لغة الإشارة بفعالية.

## الفكرة الرئيسية

يتضمن التطبيق مجموعة متنوعة من الفئات مثل الحروف الأبجدية والعائلة والطعام والحيوانات والألوان والمزيد — كل منها يحتوي على دروس وتمارين عملية واختبارات. الهدف الرئيسي هو جعل لغة الإشارة متاحة للجميع وبناء جسر التواصل بين الصم والسمع.

## المميزات الرئيسية

### التعلم والتعليم

#### دروس الفيديو
- **🎥 دروس عالية الجودة**: يتم تعليم كل إشارة (حرف أو كلمة أو عبارة) من خلال دروس فيديو قصيرة وعالية الجودة
- **📱 محسن للهاتف المحمول**: مقاطع فيديو محسنة للمشاهدة على الهاتف المحمول مع لقطات واضحة ومقربة
- **🔄 وظيفة التكرار**: يمكن للمستخدمين إعادة تشغيل مقاطع الفيديو عدة مرات حسب الحاجة
- **📊 تتبع التقدم**: تتبع مقاطع الفيديو التي تم مشاهدتها وإكمالها

#### قاموس الإشارات
- **🅰️ قاموس شامل**: قاموس قابل للبحث لجميع الحروف والكلمات، يعرض الرسوم المتحركة للإشارات المقابلة
- **🔍 بحث متقدم**: البحث حسب الفئة أو مستوى الصعوبة أو الإشارات المحددة
- **📚 الوصول غير المتصل**: تنزيل محتوى القاموس للتعلم غير المتصل
- **🔤 تعلم الحروف الأبجدية**: تعلم الحروف الأبجدية بلغة الإشارة مع الرسوم المتحركة التفاعلية

#### فئات التعلم
ينظم التطبيق المحتوى في أقسام مختلفة لتسهيل التعلم:
- **الحروف الأبجدية**: تعلم الحروف الأبجدية بلغة الإشارة
- **العائلة**: أفراد العائلة والعلاقات
- **الطعام والمشروبات**: عناصر الطعام والمشروبات الشائعة
- **الحيوانات**: الحيوانات الأليفة والبرية
- **الألوان**: مفردات الألوان بلغة الإشارة
- **الأرقام**: الأرقام والعد
- **المشاعر**: التعبير عن المشاعر والعواطف
- **الأنشطة اليومية**: الأنشطة اليومية الشائعة والروتين

#### الاختبارات التفاعلية
- **🧩 اختبار المعرفة**: بعد كل درس، يمكن للمستخدمين أخذ اختبار لاختبار معرفتهم بالإشارات
- **📊 تحليلات الأداء**: تحليلات مفصلة حول أداء الاختبار ومناطق التحسين
- **🎯 صعوبة تكيفية**: الاختبارات تعدل الصعوبة بناءً على أداء المستخدم
- **🏆 نظام الإنجازات**: فتح الإنجازات لإكمال الاختبارات والدروس

#### نظام تقييم المستخدم
- **⭐ تتبع التقدم**: يعرض التقدم في كل فئة (مثل "لقد أكملت 70% من قسم العائلة")
- **📈 تحليلات التعلم**: يعرض نسبة التعلم الإجمالية والنتيجة ومستوى المستخدم
- **🔓 نظام الفتح**: فتح فئات وإنجازات جديدة مع تقدم المستخدم
- **📊 لوحة الأداء**: لوحة "أدائي" مع الشارات والخطوط المتتالية وإحصائيات التعلم

### المجتمع والتفاعل

#### دردشات المستخدمين
- **💭 جلسات الممارسة**: الدردشة مع متعلمين آخرين للممارسة وتبادل الأفكار
- **🌍 مجتمع عالمي**: التواصل مع متعلمي لغة الإشارة في جميع أنحاء العالم
- **📱 الرسائل الفورية**: المراسلة الفورية مع المستخدمين الآخرين
- **🔒 تحكم في الخصوصية**: التحكم في من يمكنه مراسلتك ومتى

#### المناقشات الجماعية
- **👥 مجموعات قائمة على الموضوع**: الانضمام إلى مجموعات قائمة على الموضوع مثل "تعلم الإشارات للحياة اليومية"
- **📚 مجموعات الدراسة**: تكوين مجموعات دراسة مع متعلمين آخرين
- **🎯 مجموعات التحدي**: المشاركة في تحديات التعلم مع الأقران
- **📢 الإعلانات**: البقاء محدثاً بإعلانات التطبيق والمميزات الجديدة

#### الأصدقاء والتحديات
- **🧑‍🤝‍🧑 التعلم الاجتماعي**: إضافة أصدقاء ومقارنة تقدم التعلم والمنافسة في تحديات الاختبارات
- **🏆 لوحات المتصدرين**: المنافسة مع الأصدقاء والمستخدمين العالميين على لوحات المتصدرين
- **🎮 وضع التحدي**: المشاركة في التحديات المحددة زمنياً والمسابقات
- **📊 مقارنة التقدم**: مقارنة تقدم التعلم مع الأصدقاء

## المميزات المتقدمة

### المميزات المدعومة بالذكاء الاصطناعي

#### مترجم لغة الإشارة
- **🗣️ النص/الصوت إلى الإشارة**: يمكن للمستخدمين كتابة أو تسجيل الكلام (باللغة العربية أو الإنجليزية)، ويقوم التطبيق بترجمته إلى لغة الإشارة المتحركة باستخدام أفاتار ثلاثي الأبعاد
- **🤖 أفاتار ثلاثي الأبعاد**: أفاتار ثلاثي الأبعاد واقعي يؤدي إيماءات لغة الإشارة
- **🔄 الترجمة الفورية**: ترجمة فورية من النص/الكلام إلى لغة الإشارة
- **📱 متعدد المنصات**: يعمل على منصات الهاتف المحمول والويب

#### التعرف على الإيماءات بالذكاء الاصطناعي والملاحظات
- **📷 تكامل الكاميرا**: يمكن للمستخدم تسجيل إشارته الخاصة باستخدام الكاميرا
- **🧠 تحليل الذكاء الاصطناعي**: يستخدم التطبيق Mediapipe Hands API + TensorFlow لاكتشاف ما إذا كانت الإيماءة تطابق الإشارة الصحيحة
- **✅ ملاحظات فورية**: يعطي الذكاء الاصطناعي ملاحظات فورية:
  - "مثالي!" للإشارات الصحيحة
  - "تقريباً صحيح، حرك يدك أقرب إلى ذقنك" للتصحيحات
- **📊 تتبع التقدم**: تتبع التحسن في دقة الإيماءات مع مرور الوقت

#### المعلم الشخصي بالذكاء الاصطناعي
- **🤖 روبوت محادثة تفاعلي**: روبوت محادثة تفاعلي يساعد المستخدمين على ممارسة التعلم
- **💡 ردود ذكية**: ردود واعية بالسياق بناءً على مستوى تعلم المستخدم
- **📚 إرشاد التعلم**: يوفر إرشاداً حول ما يجب تعلمه بعد ذلك
- **🎯 توصيات شخصية**: يقترح دروساً بناءً على تقدم المستخدم واهتماماته

### التعلم المبني على الألعاب

#### الألعاب التعليمية
لجعل التعلم ممتعاً وجذاباً، يتضمن التطبيق عدة ألعاب مصغرة:

- **🧩 "خمن الإشارة"**: شاهد إشارة واختر المعنى الصحيح
- **✋ "طابق الكلمة"**: طابق الإشارات مع الكلمات المقابلة
- **⏱️ "إشارة السرعة"**: تحدي محدد زمنياً لاختبار رد الفعل والتمييز
- **🎯 "بناء الإشارة"**: رتب الإشارات بالترتيب الصحيح لتكوين كلمة
- **🏆 "معركة الاختبار"**: تنافس مع الأصدقاء أو المستخدمين العشوائيين في اختبارات فورية
- **🎖️ نظام المكافآت**: فوز بالشارات والنقاط والعملات لإكمال المهام أو التحديات

#### لوحة ترتيب المستخدمين وتتبع التقدم
- **📊 تحليلات شاملة**: يعرض إجمالي الإشارات المتعلمة ومتوسط نتيجة الاختبار وخط التعلم
- **🏅 نظام الإنجازات**: تقدم المستوى (مبتدئ → متوسط → متقدم)
- **📈 التقدم المرئي**: الرسوم البيانية والرسوم البيانية التي تُظهر تقدم التعلم
- **🎯 تحديد الأهداف**: تحديد وتتبع أهداف التعلم الشخصية

### مميزات إمكانية الوصول

#### دعم متعدد اللغات وإمكانية الوصول
- **🌐 دعم متعدد اللغات**: يدعم لغات متعددة باستخدام حزمة intl في Flutter
- **♿ خيارات إمكانية الوصول**: التسميات التوضيحية ومقاطع الفيديو البطيئة ووضع التباين العالي
- **🔊 الأوصاف الصوتية**: أوصاف صوتية للمحتوى المرئي
- **📱 واجهة قابلة للتخصيص**: حجم نص قابل للتعديل وألوان وتخطيط

## التقنيات المستخدمة

### الواجهة الأمامية
- **الإطار**: Flutter (Dart) لتطوير الهاتف المحمول متعدد المنصات
- **مكونات الواجهة**: Material Design 3 مع مميزات إمكانية الوصول المخصصة
- **إدارة الحالة**: Provider أو Bloc لإدارة الحالة المعقدة
- **التخزين المحلي**: Hive لتخزين المحتوى غير المتصل
- **مشغل الفيديو**: حزمة video_player لتشغيل الفيديو عالي الجودة

### الخادم الخلفي
- **وقت التشغيل**: Node.js مع Express.js أو Python مع FastAPI
- **قاعدة البيانات**: Firebase Firestore لمزامنة البيانات في الوقت الفعلي
- **المصادقة**: Firebase Authentication مع خيارات تسجيل الدخول الاجتماعي
- **تخزين الملفات**: Firebase Storage لمقاطع الفيديو والصور ورسوم الإشارات المتحركة

### الذكاء الاصطناعي والتعلم الآلي
- **التعرف على الإيماءات**: Mediapipe Hands API + TensorFlow Lite
- **معالجة الكلام**: Google Cloud Speech-to-Text API
- **الترجمة**: Google Translate API / Azure Translator
- **الأفاتار ثلاثي الأبعاد**: Ready Player Me API أو نماذج الرسوم المتحركة Unity
- **روبوت المحادثة**: Dialogflow CX أو OpenAI API

### الخدمات في الوقت الفعلي
- **الدردشة**: Firebase Realtime Database للمراسلة الفورية
- **الإشعارات**: Firebase Cloud Messaging
- **بث الفيديو**: YouTube API / Firebase Storage
- **المميزات المباشرة**: WebRTC لجلسات الممارسة المباشرة

### APIs الخارجية
- **منصة الفيديو**: YouTube API للمحتوى التعليمي
- **التحليلات**: Firebase Analytics و Google Analytics
- **الخرائط**: Google Maps API للقاءات المحلية
- **الاجتماعي**: تكامل تسجيل الدخول بـ Facebook/Google

### مميزات الذكاء الاصطناعي المتقدمة

## البدء

### المتطلبات المسبقة
- Flutter SDK 3.0+
- Node.js 16+ أو Python 3.8+
- حساب Firebase
- حساب Google Cloud (لخدمات الذكاء الاصطناعي)

### التثبيت
1. استنساخ المستودع
2. تثبيت تبعيات Flutter: `flutter pub get`
3. تثبيت تبعيات الخادم الخلفي: `npm install`
4. تكوين مشروع Firebase
5. إعداد APIs خدمات الذكاء الاصطناعي
6. تشغيل التطبيق: `flutter run`

### إعداد التطوير
- API الخادم الخلفي: `npm run dev`
- تطبيق Flutter: `flutter run`
- الاختبار: `flutter test`
